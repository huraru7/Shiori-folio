Changelog

バージョン履歴

ここでの「Ver」は詩織の設計・実装上の世代番号(このページや`library/_system/CLAUDE.md`等で 使っている呼称)であり、アプリ本体のビルドバージョン(package.json等の0.1.0表記)とは別軸。

  • Ver3.1 2026-09-16

    typeからjournalを廃止し、project/areaそれぞれの配下にkind(journal | resource) として統合(10-projects/{project}/{kind}/・20-areas/{project}/{kind}/という3階層に)。 30-resources/は「project/areaに紐づかない外部知識」専用に意味を純化し、project/area内で 生まれた意思決定・知見はkind: resourceへ移した。ふらるさん自身についての記録は新設の type: profileへ独立させ、廃止したjournalの跡地(40番台)に40-profile/として配置。 90-archive/はトップレベル5分類を1階層だけ再現する形に再設計。フォルダ階層が深くなった ことに伴い、get_source_document(記事本文表示)をsource_category直下の決め打ちから 再帰探索方式に変更した(search_libraryのpath解決と同じ考え方)。コード側の対応が先行し、 実データ(library/)の移行は別途確認の上で進める。

  • Ver3.0.2 2026-09-09

    コード実装(shiori_save.rsのVALID_TYPES/decide_destination)はVer3.0の フォルダ体系(10-projects/20-areas/30-resources/40-journal)に対応済み だったが、実データ(library/)と保存ルール文書(_system/CLAUDE.md)が Ver2.0の8フォルダ構成のまま取り残されていた不整合を発見・解消。 Ver3.0.1で追加した21件のプロフィール記事はテストデータと判明したため 削除し、唯一の実データ(profile-huraru.md)のみtype: resourceへ移行、 CLAUDE.mdをVer3.0仕様へ全面改訂した。あわせてこのリファレンスHTML 自体も実装から再度裏取りし、file数48件という古い数値の修正、STT アンロード挙動の表現修正、Orb演出/ActivityIndicator/PendingModal/ デバッグ画面の4項目を新規追加した。

  • Ver3.0.1 2026-08-24

    library/のデータを大幅更新。心理学的な自己開示の知見(段階的開示・ライフストーリー インタビュー等)を踏まえたインタビューを実施し、自己理解プロフィール記事21件を `30-resources/profile/`へ追加。実機ライブラリに残っていたVer2.0時代の旧フォルダ・ テストデータを整理し、Ver3.0のフォルダ構成に統一。このリファレンスHTMLについても、 Phase1・2直後で古くなっていた記述の修正と、図解へのパン/ズーム操作の追加を行った。

  • Ver3.0.0 2026-08-22

    詩織Ver3.0設計指示書に基づく主要実装が完了。RAGの再インデックスを検索都度スキャンから 書き込み時フック(`/reindex_file`)方式へ変更、library/のフォルダ構成とfrontmatterスキーマを 現行方式(`00-inbox/10-projects/20-areas/30-resources/40-journal/90-archive/_system`)へ 移行、`search_library`のスコア閾値廃止とページング化、図書館UIの検索結果ベース刷新と 全件閲覧画面の新設、左ゾーン(会話UI)の折りたたみ機能を追加。

実装(system/配下)から都度裏取りして書いています。細部は開発の進行で変わるため、 最終的な正としてはコード本体を当たってください。
